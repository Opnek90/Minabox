# Scripts

Hilfsskripte für Entwicklung und Setup. Von **Repository-Root** aus aufrufen: `./scripts/<script>`.

| Script | Beschreibung |
|--------|--------------|
| `dev-tools.sh` | Linting, Formatting, Pre-Commit, Venv (z. B. `./scripts/dev-tools.sh format`) |
| `setup-folders.sh` | Legt die Standard-Ordnerstruktur an (z. B. nach frischem Clone). |
| `test_display.py` | Manueller OLED-Test (Adafruit SSD1306, I2C). Kein Teil des Display-Services. |
